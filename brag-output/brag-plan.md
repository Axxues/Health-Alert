# Brag Plan: Health Alert (v3 — user-recorded tour, 30s)

## What is this app?
Health Alert (BantayHealthAI) is a real-time multi-syndromic outbreak prediction and early-warning command center for Philippine LGUs — bi-LSTM trajectory vectors, automated DOH clinical action playbooks, and a 276-node sentinel network on one intelligence screen.

## The angle
The user drives: a real screen recording of a human using the system in light mode — dashboard, intelligence deep-dive, all-diseases risk map down to a barangay slide-over. No scripted cursor, no mockups. The hook and outro cards frame the tour.

## Hook (first 3 seconds)
Dark screen over the product's own words: "Today's outbreak outlook, before the clinic opens." Then: watch someone use it.

## Key moments (the middle)
- Light-mode command center with the 276-node Epi-Curve and bi-LSTM projection window.
- Intelligence Sentinel Deep-Dive with live demo data.
- All-diseases Night-Ops map (276 hotspots) drilled to Brgy. Poblacion, San Carlos City: High Outbreak Risk, Dengue 80 cases · 35% surge, with Deep-Dive actions per syndrome.

## Outro / punchline
"Health Alert. See it before it spreads."

## User flow worth showing
Sign in (guest demo) → command center flags the surge → risk map locates the cluster → alert ledger broadcasts and acknowledges. Shown through the real screens in that order.
